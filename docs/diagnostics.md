# 闪退与本地诊断记录

当前开发分支已加入本地诊断，尚未发布。公开的 **1.2.1-desktop（构建 70）** 不包含此功能。

加入此功能的桌面版会将启动、退出、运行阶段和未处理的 Dart／Flutter 异常写入本机文件。Windows 还记录原生启动阶段、窗口关闭和未处理的原生异常；能够执行崩溃处理器时会生成 `.dmp` 小型转储。

## 用户如何提供记录

- **Windows**：按 `Win + R`，输入 `%LOCALAPPDATA%\Plana App Desktop\diagnostics` 后回车。将这个目录压缩后提供给维护者，最好在下一次闪退后尽快收集。
- **macOS**：在访达中按 `⌘⇧G`，输入 `~/Library/Logs/Plana App Desktop`。原生系统崩溃报告仍由 macOS 保存在 `~/Library/Logs/DiagnosticReports`。

`dart-*.log` 是运行记录和 Dart／Flutter 异常；Windows 的 `native-*.log` 是原生窗口与引擎记录，同名 `.dmp` 是崩溃转储。日志包含时间和软件版本，正常退出记录可帮助区分主动关闭与异常终止。

## 保留与隐私

每类保留最近 **10 次启动**的记录。每个 Dart 日志达到 **1 MiB** 时轮转，额外保留同会话的一份 `.log.1`；Windows 转储随所属会话一起清理。记录在进程退出后保留，升级和卸载不会主动删除；用户也可以手动删除整个诊断目录。

记录仅保存在本机，不会自动上传。代码不主动记录请求正文、提示词或图片字节，错误文本中的常见令牌、授权字段和 URL 查询参数会被遮蔽。错误文本可能包含文件路径；`.dmp` 可能包含部分进程内存，请只向可信的维护者提供。

目录不可写或磁盘已满时，记录失败不会阻止应用启动。强制结束、内存耗尽、引擎载入前的失败或部分系统快速终止不一定能生成转储；已有的启动与运行记录仍可帮助排查。没有 `.dmp` 不等于没有异常。
