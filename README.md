# Plana App Desktop 发布图片存档

本分支保存各版本的界面对比图，供 GitHub Release 正文引用。

安装包、校验文件和构建清单位于[发布页面](https://github.com/shenghuo2/Plana-App-Desktop/releases)。

- [1.2.1-desktop 对比图](v1.2.1-desktop/)：18 张；来源提交与 SHA-256 见目录中的 `manifest.json`。

图片按版本分别保存。Release 正文使用固定到具体提交的 raw.githubusercontent.com 地址，后续增加版本不会改变已有图片链接。
